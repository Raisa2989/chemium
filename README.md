# ХимиУм — учебник-тренажёр по химии для 8–11 классов

Полноценное PWA-приложение: полный школьный курс химии с теорией, интерактивным
тренажёром, справочником и периодической таблицей. Устанавливается на телефон
или компьютер как приложение и работает **офлайн**.

**Приложение полностью статическое: сервера, API и базы данных нет.**
После сборки это просто набор файлов (HTML/CSS/JS), который размещается
на любом статическом хостинге. Прогресс занятий хранится на устройстве.

## Возможности

- **2 этапа**: 8–9 классы (подготовка к ОГЭ) и 10–11 классы (подготовка к ЕГЭ)
- **2 уровня** в каждом этапе: базовый и углублённый (углублённый = база + 107 задач повышенной сложности)
- **75 тем**, **752 вопроса** с подробным разбором каждого ответа
- **4 типа заданий**: выбор ответа, множественный выбор, ввод ответа, соответствие
- **Интерактивная периодическая таблица** и справочник (растворимость, ряд активности, индикаторы, качественные реакции)
- **Прогресс и достижения** — хранятся локально на устройстве
- **PWA**: манифест, service worker, офлайн-режим, установка на телефон/десктоп

## Публикация

### Шаг 1. GitHub — бесплатно, с автоматической сборкой

1. Создайте аккаунт на [github.com](https://github.com) (если ещё нет).
2. Создайте репозиторий: кнопка **New** → имя (например, `chemium`) → **Create repository**.
3. Загрузите код из этого архива в репозиторий:

   **Вариант А — через программу [GitHub Desktop](https://desktop.github.com) (без команд):**
   распакуйте архив на компьютер → в GitHub Desktop: **File → Add repository → Create a New Repository** →
   выберите папку с распакованным проектом → **Create** → **Publish repository**.

   **Вариант Б — через терминал (5 команд):**
   ```bash
   cd путь/к/распакованной/папке
   git init
   git add .
   git commit -m "ХимиУм"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/chemium.git
   git push -u origin main
   ```

4. Включите публикацию: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Откройте вкладку **Actions** и дождитесь зелёной галочки «Сборка и публикация» (2–3 минуты).
6. Готово. Адрес сайта — в **Settings → Pages**: `https://ваш_логин.github.io/chemium/`.

В репозиторий уже вложен файл `.github/workflows/deploy.yml` — GitHub сам собирает
и публикует сайт при каждом обновлении кода. Устанавливать что-то на компьютер не нужно.

> **Свой домен на GitHub Pages (опционально):**
> Settings → Pages → **Custom domain** → введите домен. У регистратора (например, reg.ru)
> добавьте DNS-записи: `A` для `@` → `185.199.108.153`, `185.199.109.153`,
> `185.199.110.153`, `185.199.111.153`; `CNAME` для `www` → `ваш_логин.github.io`.
> После проверки включите **Enforce HTTPS**. Так как сайт станет открываться в корне
> адреса, откройте `.github/workflows/deploy.yml` и в шаге «Собрать сайт для GitHub Pages»
> замените строку `NEXT_PUBLIC_BASE_PATH: ${{ steps.bp.outputs.path }}` на `NEXT_PUBLIC_BASE_PATH: ''`.

### Шаг 2 (альтернатива). Хостинг reg.ru со своим доменом

1. Купите у reg.ru обычный **«Хостинг сайтов»** (минимальный тариф — без Node.js и БД)
   и домен, если его ещё нет.
2. Скачайте готовые файлы сайта: GitHub → вкладка **Actions** → последний успешный запуск
   «Сборка и публикация» → внизу блока **Artifacts** → **chemium-static-site** → скачать и распаковать.
   (Если запусков давно не было — кнопка **Run workflow** создаст свежий архив.)
3. В панели управления хостингом reg.ru откройте **Файловый менеджер** → папка `public_html` →
   удалите стандартный `index.html` → загрузите туда **всё содержимое** распакованной папки
   (файлы `index.html`, папки `_next`, `icons` — не саму папку целиком).
4. Включите HTTPS: панель → раздел **SSL-сертификаты** → бесплатный **Let's Encrypt**
   для домена → после выпуска включите перенаправление на HTTPS.
   (HTTPS обязателен для установки PWA.)
5. Откройте `https://ваш-домен` — приложение работает, браузер предложит установить его.

### Обновление приложения

- Изменился код → загрузите изменения в репозиторий → GitHub сам пересоберёт и опубликует сайт.
- Для reg.ru: скачайте свежий архив `chemium-static-site` из Actions и перезалейте файлы в `public_html`.

## Как установить приложение (памятка для пользователей)

- **Android / Chrome / Edge:** меню браузера → «Установить приложение» (или баннер в самом приложении).
- **iPhone / iPad:** Safari → «Поделиться» → «На экран “Домой”».
- **Windows / macOS:** значок установки справа в адресной строке браузера.

После установки интернет не нужен: теория, тренажёр, справочник и таблица работают офлайн.

## Хранение данных

Всё хранится локально на устройстве (localStorage): выбранные этап и уровень,
прогресс по темам, достижения, настройки. Приложение не отправляет ни одного
запроса на какой-либо сервер. Прогресс не переносится между устройствами;
очистка данных браузера сбрасывает его.

## Локальная разработка (по желанию)

```bash
bun install     # нужен Bun 1.1+ (https://bun.sh) или Node.js 20+ с npm
bun run dev     # http://localhost:3000
bun run build   # статическая сборка → папка out/
bun run lint    # проверка кода
```

Весь учебный контент — в `src/data/grade8…grade11/` (разделы → темы → вопросы);
структура описана в `src/data/types.ts`. Количество вопросов: `bun scripts/count-stats.ts`.

## Структура проекта

```
src/app/         — страница и лэйаут (App Router)
src/components/  — оболочка, экраны, тренажёр, UI-kit (shadcn/ui)
src/data/        — УЧЕБНЫЙ КОНТЕНТ: теория и вопросы по классам
src/lib/         — стор (zustand + localStorage), темы этапов, рендер формул
public/          — manifest.webmanifest, sw.js (офлайн), иконки, logo.svg
.github/         — авто-сборка и публикация на GitHub Pages (Actions)
brand/           — бренд-материалы: брошюра, логотипы, баннер
scripts/         — служебный скрипт статистики контента
```
